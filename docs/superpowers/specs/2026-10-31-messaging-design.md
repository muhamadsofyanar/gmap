# Free messages, recipient selection, refined CRM
User reports template-only sending, all-project broadcasts and plain interface. Implement editable plain-text messages (1–4000 characters), optional template starters, admin composer directly in linked CRM inbox. Preserve admin-only sending and contact blocks. Existing member permissions unchanged. Broadcast requires explicit nonempty recipient IDs selected from searchable project contacts; selection persists during search; server validates project/CRM/workspace scope, rejects invalid selection and deduplicates phone numbers. Manual text uses template_id=0 sentinel (existing unsigned columns, no foreign keys); no schema or environment changes. Existing broadcast snapshots/resume preserved. Exact request token content binding prevents token reuse with changed payload. Refine teal visual system, focus states, hover/dialog/bubble motion with reduced-motion support. No automatic sending or edits to already sent messages. Keep webhook receiver unchanged.
Approach: extend existing sending and broadcast routes/ledger. A new provider stack or separate campaign engine would duplicate working behavior, so keep native PHP/CSS/JS.
